# Design System

Every visual value lives in **one file: `src/styles/tokens.css`**. Tailwind v4 reads it (`@theme`)
and generates the utilities, so a token has **the same name in the docs, Storybook and the code**.
Nobody translates a design name into a different code name, which is how design drifts after handoff.

## How the tokens are layered

| Layer | Where | Example |
| --- | --- | --- |
| 1. Raw palette | `:root` in `tokens.css` | `--raw-green: #26422a` |
| 2. Theme (light / dark) | `:root`, `[data-theme="dark"]` | `--theme-bg-page: var(--raw-white)` |
| 3. Category accent | `[data-category="coffee"]` etc. | `--accent: var(--raw-espresso-600)` |
| 4. Semantic tokens | `@theme` | `--color-bg-page: var(--theme-bg-page)` |
| 5. Utilities | generated by Tailwind | `bg-bg-page`, `text-accent`, `rounded-card` |

`--color-*: initial` removes Tailwind's default palette, so only Ondo colours exist.

**Theming is attributes, not components.** One `ShopCard` serves coffee, tea, matcha and every add-on:
`data-category` on any ancestor swaps the accent, and `data-theme="dark"` swaps the whole surface
set. Components only ever use semantic utilities, so they never need to know which theme they're in.

## Colour

Playful and colour-blocked. Five brand colours, each with one clear job, used in big confident
blocks (a whole card tint, a whole button) rather than thin lines. Everything else is derived and
contrast-checked.

| Brand colour | Hex | Job | Token |
| --- | --- | --- | --- |
| **Vanilla** | `#FFEEBC` | The canvas: page tone, quiet fills, add-on tint, text on dark | `--raw-vanilla` → `bg-bg-subtle` (page and cards use lighter Vanilla) |
| **Bistre** | `#5D372A` | Text and coffee | `--raw-bistre` → `text-text-primary`, coffee accent |
| **Cal Poly Green** | `#26422A` | The brand: secondary buttons, tabs, toggles, matcha, the dark theme | `--raw-green` → `brand`, matcha accent |
| **Columbia Blue** | `#D2E8FF` | Selection and info: selected cards, info panels, tea | `--raw-columbia` → `bg-primary-subtle`, tea tint |
| **Flame** | `#EA672D` | The spark: the main call to action and small highlights | `--raw-flame` → `action`, `spark` |

### Roles, in order of how much of the screen they cover

1. **Vanilla + Bistre**: the structure. Warm cream surfaces, brown text. Most of every screen.
2. **Green, Blue and the category tints**: the personality. Category blocks, selected states,
   secondary buttons, info panels.
3. **Flame**: the spark, roughly 5–10% of a screen. Only the main call to action on each page
   (Go to checkout, Add to box · price, View your box), the savings highlight and the "in your
   box" outline on cards. If it spreads, it stops working.
4. **Danger red**: warnings only (contains something you avoid, above your caffeine limit).
   Flame is never used for warnings.

### Flame buttons use dark text

White on Flame is only 3.2:1, so Flame buttons carry dark Bistre text (`#2B1810`, 5.2:1) in both
themes. That keeps the bright Flame itself on the button instead of a muddier deep orange.

| Tone | Hex | Use |
| --- | --- | --- |
| Flame | `#EA672D` | Button fill, borders, highlights (3.0:1 on the page: non-text only) |
| Flame tint / deep | `#FDE3D2` / `#A33E15` | Savings highlight: deep Flame text on the tint (5.3:1) |
| Dark-theme tint / light | `#3E2516` / `#F59A68` | The same highlight on the dark page (6.6:1) |

### Categories are colour-blocked

Each drink has its own colour from the palette, and is also told apart by **icon and pack
shape** (bean + bag, leaf + box, whisk + tin), so colour is never the only cue:

## Typography

Both families are free under the **SIL Open Font License**, so they're **self-hosted** from
`public/fonts` (Latin subset, licences alongside). `@font-face` is at the top of `tokens.css`; the
layout preloads the two most used files. Source Sans Pro is now published as **Source Sans 3**
(same family, updated); the stack falls back to the old name too.

| Family | Utility | Use |
| --- | --- | --- |
| Fira Sans (600, 700, 800) | `font-heading` | Headlines: wordmark, page titles, section titles |
| Source Sans 3 (variable, 200–900) | `font-sans` | Body and UI: labels, buttons, descriptions, prices |
| System monospace | `font-mono` | Brew data (ratio, temperature, time), small eyebrows |

| Utility | Mobile | Desktop (≥1024px) | Usually |
| --- | --- | --- | --- |
| `text-display` | 56 / 56 | 96 / 92 | heading 700, -0.03em |
| `text-heading` | 28 / 32 | 40 / 44 | heading 700, -0.02em |
| `text-title` | 20 / 24 | 22 / 28 | heading 700 (section titles) or sans (big prices) |
| `text-body-lg` | 18 / 28 | 20 / 30 | sans 400 |
| `text-body` | 16 / 24 | 16 / 24 | sans 400 |
| `text-body-sm` | 14 / 20 | 14 / 20 | sans 400 (dense mobile copy) |

## Spacing and layout

- **Spacing unit is 1px** (`--spacing: 1px`), so `p-16` = 16px. Use the steps:
  0 2 4 8 12 16 20 24 32 40 48 64 80 96 128.
- Breakpoint: `lg:` = 1024px.

| Token | Mobile | Desktop |
| --- | --- | --- |
| `--layout-margin` (`px-margin`) | 16px | 64px |
| `--layout-gutter` (`gap-gutter`) | 16px | 24px |
| `max-w-frame` | 402px | |
| `max-w-column` | 560px (one column on tablets) | |
| `max-w-content` | 1200px | |

## Radius, borders, elevation, motion

| Utility | Value | Use |
| --- | --- | --- |
| `rounded-sm` | 6px | Inputs, chips |
| `rounded-card` | 16px | Cards |
| `rounded-panel` | 28px | Hero panels, sheets |
| `rounded-pill` | 999px | Buttons, badges, stepper |
| `shadow-card` | `0 1px 2px` + `0 4px 12px` at very low alpha | Cards (with a border) |
| `shadow-raised` | `0 1px 2px` + `0 8px 24px` at low alpha | Hover, popovers |
| `shadow-bar` | `0 -4px 16px` | Bars fixed to the bottom |
| `duration-120` / `duration-200` | 120ms / 200ms | Hover, press, expand |
| `ease-brew` | `cubic-bezier(.2,.7,.2,1)` | All transitions |

Motion turns off under `prefers-reduced-motion`.

**Logo:** a kettle with the name across its handle, so it doubles as the wordmark. Source art
(1093 × 1439, one per brand colour) is in `public/brand/logo`. The header uses 3× web copies,
`public/brand/ondo-logo-green.webp` and `ondo-logo-vanilla.webp` (109 × 144, about 6KB), shown at
36 × 48. Keep the 3:4 shape: never force it into a square. Green on light pages, Vanilla on dark,
swapped by the `logo-light` / `logo-dark` utilities. The favicon and sharing image still use the
old emblem.

**Utilities:** `highlight` (Flame-tint pill behind a word), `pb-safe` (clears the iPhone home bar),
`stretched-link` (whole card tappable), `scrollbar-none`. Together they mean components never need
arbitrary values.

**Texture:** the dark theme can use a CSS film-grain overlay (`.grain`, an inline SVG noise), echoing
the moodboard. It's decoration only and sits under `aria-hidden` content.

## Components (`src/components`)

The screens follow the structure of my earlier meal-delivery prototype (order summary, menu with
tabs, product page, sticky bars), rebuilt with Ondo's tokens. Everything is mobile first: designed
at 402px, then `md:` / `lg:` add columns.

### Building blocks

| Component | Notes |
| --- | --- |
| `Icon` | Line icons on a 24px grid, `currentColor`. Decorative unless labelled. |
| `Button`, `IconButton` | `primary`, `accent`, `secondary`, `ghost`. 44px minimum. |
| `Chip`, `Pill`, `ToggleChip` | Tasting notes (`note`), quiet labels (`outline`), label + value (`Pill`, e.g. "Size 250g"), on/off filters. A disabled `ToggleChip` fades to 40%. |
| `CategoryBadge` | Coffee / Tea / Matcha / Gear / Bites / Sweeteners, each with its icon (bean, leaf, whisk, kettle, cookie, jar). Sets its own `data-category`. |
| `CaffeineMeter` | 5 beans filled to the level + text. `compact` keeps the words for screen readers only. |
| `BrewGuide` | Ratio, water, time in mono; tea adds steeps, matcha adds the whisk. |
| `Stepper` | 0 → outlined "Add to box"; 1 → bin + plus; 2+ → minus + plus. 24px icons, 44px hit areas. Sizes `default`, `compact`, `bar`. |
| `Price` | Display face, tabular figures; optional was-price and "each". |
| `ProductImage` | Pack shot. Every product uses its photo (`item.image`: transparent 3:4 art from `public/brand/shop`, web copies at 304 and 684px in `public/brand/shop/web`) on `bg-bg-product`; pass `sizes` for its display width. An item without one falls back to a drawn pack or its category icon. |

### Patterns

| Component | Used on | Notes |
| --- | --- | --- |
| `PageHeader`, `SavingsLine` | All pages | Back, wordmark or title, light/dark switch. |
| `Steps` | Checkout | Progress, not clickable. Current step = bold + 3px brand underline (`aria-current="step"`); done steps get a tick. |
| `OrderReview` | Checkout | "Your first box": count, cadence and total; expands to every line, subtotal, saving, delivery (£3.95 struck, FREE) and the first-box total, plus a discount-code field. |
| `WalletButtons` | Checkout | Static demo buttons, no payment API: Apple Pay as button artwork (from the Apple Pay / Google Pay Buttons Figma file), Google Pay drawn by Google's script. "Pay with…" for subscriptions, "Buy with…" for one-off; black on light, white on dark; both full width, 44px tall (Apple artwork centred on Apple's black or white); Apple Pay first. Tapping goes to the order confirmation. |
| `TextField`, `Checkbox`, `Divider` | Checkout | 48px inputs with label, hint and error (danger colour, `aria-invalid`, announced); native checkbox in the brand colour; "or pay with card" rule. |
| `DatePicker` | Your box, checkout | Trigger (`field`: bordered date; `link`: "Change") + calendar popover, Monday-first. Earliest date is **tomorrow** (today and the past are disabled). Arrows, Home/End, Page Up/Down, Enter, Escape. Default: a week from today, set in the browser. |
| `PreferencesCard` | Your box | The onboarding answers. Collapsed to the goal; open, a summary (label / value rows) with "Edit preferences", which swaps in the controls: goal, people and cups a day (pill radiogroups), drinks and brew kit (toggle chips), caffeine limit (1–5), avoids. A change re-ranks the rail. |
| `DeliveryCard` | Your box | Collapsed to "Every 30 days · Tue 3 Nov" (opens on a link to `#delivery`). Open: a suggestion with its reason, how often (segmented pill radiogroup with the saving under each option and "skip, swap or pause" below), then the first delivery date and the next delivery. The suggestion never changes the choice by itself. |
| `OrderSummary` (`OrderGroup`, `ItemCard`, `ItemThumbnail`) | Your box | Drinks and Add-ons, each collapsible and sub-grouped by category; collapsed groups show thumbnails. A line that no longer fits the preferences shows why, and stays. |
| `SuggestionRail`, `SuggestionCard` | Your box, item page | 148px cards with the reason line. Scrolls sideways at every width, so the desktop sidebar stays short enough to keep the total in view. Hidden when empty. |
| `BoxTotal` | Your box | Fixed to the bottom on mobile, a card in the sticky sidebar from 1024px. `aria-live`. |
| `CategoryTabs` | Shop | 44px tabs, active = bold + 3px underline, scroll sideways on mobile, centred on desktop. |
| `CaffeineFilter` | Shop (drink tabs) | A row of `ToggleChip`s: All · Low · Medium · High, each with its count. Single choice; tapping the selected band returns to All; empty bands are disabled. |
| `ShopCard` | Shop | 2 columns on mobile, 3 at 768px, 4 at 1024px. States: available, in box (Flame ring), with reason, unavailable (faded, reason, no stepper). |
| `CollapsibleSection` | Shop | "Above your caffeine limit (n)", "Contains things you avoid (n)", "Back soon (n)". |
| `ViewBoxBar` | Shop | "View your box · n items · £total", always in view. |
| `BrewHighlights`, `DetailAccordion`, `OrderBar` | Item page | Stats row + a "Contains" box that is never collapsed; accordions; a pinned order bar that becomes quantity + stepper once it's in the box. |

## States

| State | Behaviour |
| --- | --- |
| Nothing to suggest | Rail hidden, no empty box. |
| Over caffeine limit / contains an avoid | Never suggested. In the shop: tucked into a collapsed section with the reason. In the box: kept, with a note. On the item page: the order bar shows the reason. |
| Out of stock | "Back soon" section; order bar shows "Back soon". |
| Added from rail | Card border turns Flame; add becomes a stepper; rail order doesn't change until the page reopens or a preference changes. |
| Empty group | "No drinks yet…" / "Nothing to brew with yet…" pointing to the suggestions. |
| Long name | 1 line in the box, 2 lines on cards and the item header. |
| Tap a card | Opens `/item/[id]` (the name is stretched over the card); steppers sit above it, so they never navigate. |

## Accessibility

- `:focus-visible`: 2px outline in `accent`, 2px offset, on every interactive element.
- 44px minimum tap targets.
- Goal picker and plan cards are radiogroups with arrow-key support.
- Prices have screen-reader text ("£12.50 every 4 weeks"); the total announces changes.
- Caffeine level always has a text label.
