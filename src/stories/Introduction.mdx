# Ondo design system

Ondo is a fictional caffeine subscription: coffee, tea, matcha and the gear to brew them.
This Storybook documents its design system, built with Claude and code.

## The idea in one line

**One set of components, themed by attributes.** Every visual value lives in `src/styles/tokens.css`.
Components only use semantic utilities (`bg-bg-surface`, `text-accent`), and two attributes decide
how they look:

- `data-theme="light" | "dark"` swaps the surfaces (white, or the brand's near-black olive).
- `data-category="coffee" | "tea" | "matcha"` swaps the accent.

Use the **Theme** and **Accent** menus in the toolbar to see every story in each combination.

## Layers

1. Raw palette (`--raw-koi-500`)
2. Theme (`--theme-bg-page`)
3. Category accent (`--accent`)
4. Semantic tokens in `@theme` (`--color-accent`)
5. Tailwind utilities (`text-accent`)

## Working with AI tools

`CLAUDE.md` and `doc/agent.md` tell Claude Code (or any AI coding tool) the rules: no hard-coded
values, no branching on category for styling, stories for every state, contrast checked to AA.
That file is part of the system: it's what keeps generated UI on-brand.
